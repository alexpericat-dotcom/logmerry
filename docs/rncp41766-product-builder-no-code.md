## Blocs de compétences

Quatre blocs obligatoires et un bloc optionnel au choix.

- BC01 : Cadrer le produit no code et la stratégie de valeur.
- BC02 : Concevoir l'architecture fonctionnelle et les intégrations no code.
- BC03 : Construire la solution no code et assurer la qualité.
- BC04 : Déployer, opérer et gouverner les produits no code.
- Option A, BC05 : plateformes web ou mobile no code.
- Option B, BC06 : environnements XR no code.
- Option C, BC07 : applications no code IA-driven (prompts, agents, RAG et sa gouvernance, intégration, évaluation qualité/coûts).

Évaluation : mises en situation professionnelle simulée (projets) avec livrables et soutenances orales.

## Emplois accessibles (liste de la fiche)

Product builder no code, manager / chef de projet no code, product owner no code, consultant no code et automatisation, développeur no code web / mobile, intégrateur d'applications no code.
